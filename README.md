# Neomora Club Manager

Minimal NestJS + Prisma project for managing club operations.

## Quick setup

1. Install dependencies:

```bash
npm install
```

2. Create a GitHub repository (via website or `gh` CLI) and add it as remote:

```bash
git remote add origin <your-github-repo-url>
git branch -M main
git push -u origin main
```

Or create + push in one command (requires `gh`):

```bash
gh repo create <repo-name> --public --source=. --remote=origin --push
```

## Local development

```bash
npm run start:dev
```
